# Clone a Test With Its Questions

_Last updated: July 14, 2026, 10:40 AM (Last updated 2 months ago)_

Clone a test when you need a reusable assessment structure while preserving a separate configuration for a new hiring workflow. Review the copied questions and settings before publishing.

# Prerequisites

- Permission to manage tests in **HackerRank for Work**.
- An existing test that can serve as the source.
- The intended changes for the new assessment.

# Clone the assessment

To clone a test:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** or the test library.
3. Locate the source test.
4. Open the test actions and select **Duplicate**, **Clone**, or the available copy option.
5. Enter a new name for the cloned assessment.
6. Review the copied questions, sections, scoring, timing, and candidate settings.
7. Remove or replace questions that should not be reused.
8. Select **Save** or **Create Test**.
9. Preview the new assessment before inviting candidates.

**Note:** Treat cloned assessments as separate resources. Changes to the source test should not be assumed to update the cloned version.

For duplicating tests, see [📄 Duplicate a Test](/articles/2692738140).
