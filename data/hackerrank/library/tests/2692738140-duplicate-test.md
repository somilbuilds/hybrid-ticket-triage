# Duplicate a Test

_Last updated: August 13, 2026, 9:15 AM (Last updated 1 month ago)_

Duplicate an existing test when you need a similar assessment with different questions, timing, or candidate settings. Review the copied configuration before inviting candidates.

# Prerequisites

- Permission to manage tests in **HackerRank for Work**.
- An existing test that can be used as the starting point.
- The intended name and configuration for the new test.

# Create a duplicate

To duplicate a test:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** or the test library.
3. Locate the test you want to use as a template.
4. Open the test's actions menu and select **Duplicate** or the available copy option.
5. Enter a new test name.
6. Review the copied questions and test settings.
7. Update timing, candidate access, notifications, and other settings as required.
8. Select **Save** or **Create Test**.
9. Open the new test and verify the configuration before sending invitations.

**Note:** Treat the duplicated assessment as a separate workflow. Do not assume changes made to the original test will automatically apply to the duplicate.

For question organization, see [📄 Manage Question Tags and Categories](/articles/9921384729).
