# Hidden Test Cases

_Last updated: August 31, 2026, 2:40 PM (Last updated 17 days ago)_

Hidden test cases allow you to evaluate candidate submissions without displaying the expected inputs and outputs. This article explains how to add and manage hidden test cases for coding questions.

# Prerequisites

- You must have permission to edit the coding question.
- The question must contain a valid coding problem and evaluation setup.
- Prepare the input and expected output for each hidden case.

# Adding hidden test cases

To add hidden test cases:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and open the coding question.
3. Select **Edit** and open the **Test Cases** section.
4. Click **Add Test Case**.
5. Enter the required **Input** and expected **Output**.
6. Enable the option to make the test case hidden, if available.
7. Add additional cases for boundary conditions and expected failure scenarios.
8. Save the test cases.
9. Run the question's available validation or preview to confirm that the cases evaluate correctly.

**Note:** Hidden test cases are intended for evaluation and should not contain information that candidates need to understand the problem. Keep candidate-visible examples separate from hidden evaluation cases.

If candidates receive unexpected scores, review the hidden cases for incorrect expected output or formatting requirements. For evaluation logic beyond standard test cases, see [📄 Configure a Custom Checker](/articles/5186293740).
