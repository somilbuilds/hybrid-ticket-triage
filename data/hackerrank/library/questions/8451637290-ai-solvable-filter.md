# AI Solvable Filter

_Last updated: September 4, 2026, 10:50 AM (Last updated 13 days ago)_

The AI Solvable filter helps identify library questions based on whether their expected solution can be addressed by commonly available AI coding assistants. Use the filter as a question-discovery aid when building assessments.

# Prerequisites

- You must have access to the HackerRank for Work question library.
- The library must contain questions that can be filtered.
- Confirm the assessment objective before selecting questions.

# Using the AI Solvable filter

To filter questions:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and select **Questions**.
3. Open the available **Filters** panel.
4. Locate the **AI Solvable** filter.
5. Select the desired AI solvability value or classification.
6. Review the filtered question list.
7. Open individual questions to review their difficulty, topic, test cases, and other available metadata.
8. Add appropriate questions to your assessment after reviewing the complete question configuration.

**Note:** The AI Solvable classification is a discovery and assessment-design aid. Review the actual question, evaluation criteria, and assessment requirements before relying on the classification for a hiring decision.

If the filter does not appear, verify that the feature is available for your organization and that your account has access to the relevant library functionality. See [📄 Search and Filter Library Questions](/articles/5937182640).
