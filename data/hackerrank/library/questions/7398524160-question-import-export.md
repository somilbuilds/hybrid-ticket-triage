# Question Import and Export

_Last updated: September 2, 2026, 11:55 AM (Last updated 15 days ago)_

You can use the available import and export tools in HackerRank for Work to move supported library questions between environments or maintain question backups. Review the question structure before importing a large set of questions.

# Prerequisites

- You must have permission to manage library questions.
- Prepare a supported question export file for import.
- Confirm that the questions are compatible with the destination library.

# Exporting questions

To export questions:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and select **Questions**.
3. Select the questions you want to export.
4. Click **Export**.
5. Select the available format or export option.
6. Save the generated file to your device.
7. Verify that the exported file contains the expected questions.

# Importing questions

To import questions:

1. Open **Library** and select the available **Import** option.
2. Choose the supported question file from your device.
3. Review the validation results.
4. Correct any invalid fields or unsupported question settings.
5. Start the import and review the resulting questions in the library.

**Note:** Not every question setting may be portable between environments. Review imported questions, test cases, and evaluation settings before using them in an assessment.

For custom evaluation configurations, see [📄 Custom Checker](/articles/6287413950).
