# View Question Version History

_Last updated: September 1, 2026, 9:50 AM (Last updated 2 weeks ago)_

Question version history helps you identify changes made to a question over time. Reviewing earlier versions can be useful when investigating unexpected candidate results or changes to question content.

# Prerequisites

- Permission to view or manage questions in **HackerRank for Work**.
- Access to the question you want to investigate.

# Review question history

To review changes to a question:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Library** and locate the relevant question.
3. Open the question details.
4. Select **Version History** or the available history option.
5. Review the recorded versions and compare the question content, configuration, and associated changes.
6. Identify the version that was active when the assessment was delivered.
7. Use the historical information when investigating a candidate report or question configuration issue.

**Note:** Editing a question after an assessment has been created does not necessarily mean that previously recorded candidate results should be interpreted using the newest question configuration. Check the assessment and question history together.
