# Create Coding Question

_Last updated: September 3, 2026, 11:25 AM (Last updated 14 days ago)_

You can create a custom coding question in the HackerRank for Work library and configure the problem statement, supported languages, test cases, and evaluation settings.

# Prerequisites

- You must have permission to create or manage library questions.
- Prepare the problem statement and expected solution behavior.
- Determine the programming languages candidates should be able to use.

# Creating a coding question

To create a coding question:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and select **Questions**.
3. Click **Create Question** and select **Coding**.
4. Enter a **Question Name** and problem statement.
5. Configure the **Input Format**, **Output Format**, and any constraints or examples.
6. Select the programming languages that candidates can use.
7. Add the required test cases and define the expected outputs.
8. Configure scoring or evaluation settings as needed.
9. Save the question and review it using the available preview or test option.
10. Publish the question when it is ready to use in an assessment.

**Note:** Test cases determine how candidate submissions are evaluated. Include sufficient cases to validate expected behavior without exposing hidden evaluation data.

For questions that require custom evaluation logic, see [📄 Configure a Custom Checker](/articles/5186293740).
