# Manage Question Tags and Categories

_Last updated: August 30, 2026, 2:35 PM (Last updated 3 weeks ago)_

Tags and categories make it easier to organize questions and locate appropriate content when building assessments. Consistent tagging also helps teams maintain a reusable question library.

# Prerequisites

- Question-library access in **HackerRank for Work**.
- Existing questions that you want to organize.
- A consistent naming convention for your team.

# Update question organization

To manage tags and categories:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Library** and locate the question.
3. Open the question details or editing view.
4. Review the existing **Tags** and **Category** values.
5. Add relevant tags that describe the skill, topic, or intended use.
6. Remove tags that are inaccurate or obsolete.
7. Select **Save**.
8. Search the library using the updated values to confirm that the question is discoverable as expected.

**Note:** Prefer stable, reusable tags over highly specific labels that only apply to one assessment. Avoid creating multiple tags with nearly identical meanings.

For importing library content, see [📄 Question Import and Export](/articles/7398524160).
