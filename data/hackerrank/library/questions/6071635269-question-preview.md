# Preview a Question Before Publishing

_Last updated: July 15, 2026, 2:25 PM (Last updated 2 months ago)_

Preview a question before publishing or adding it to an assessment to catch unclear instructions, incorrect examples, and evaluation problems.

# Prerequisites

- Permission to manage questions in **HackerRank for Work**.
- A draft or editable question.
- Representative inputs for testing the question.

# Preview the question

To preview a question:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Library** and locate the question.
3. Open the question details.
4. Select **Preview** or the available preview action.
5. Read the candidate-facing instructions from start to finish.
6. Test the example inputs and review the expected outputs.
7. Run representative edge cases when the preview supports execution.
8. Correct any content or evaluation issues and preview the question again before publishing.

**Note:** Preview the question as a candidate would see it. Administrative metadata can hide issues that become obvious when the complete candidate-facing instructions are displayed.

For editing reusable content, see [📄 Edit Question Details](/articles/3714862593).
