# Leaked Question Replacement

_Last updated: September 3, 2026, 4:15 PM (Last updated 14 days ago)_

If a question used in an assessment has been shared publicly, replace it with an appropriate question from the HackerRank for Work library. Review the affected assessment and any active tests before making changes.

# Prerequisites

- You must have permission to edit the relevant assessment or question.
- Identify the question that has been exposed.
- Prepare a replacement question with comparable requirements.

# Replacing a leaked question

To replace a leaked question:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and locate the affected question.
3. Confirm the question is the one that was exposed and review its current usage.
4. Search the library for a suitable replacement question.
5. Open the assessment or test where the leaked question is used.
6. Select **Edit** and locate the affected question.
7. Remove the exposed question and add the replacement question.
8. Review the question order, scoring, time limits, and test configuration.
9. Save the updated assessment.
10. If the test is already active, verify how the change affects existing candidate attempts before applying it.

**Note:** Do not assume that replacing a library question automatically changes every assessment where the question was previously used. Review each affected test and assessment configuration separately.

If the exposed question is part of a question set or shared library, consider restricting its future use. For evaluation configuration, see [📄 Hidden Test Cases](/articles/5176382940).
