# Edit Question Details

_Last updated: July 31, 2026, 2:40 PM (Last updated 1 month ago)_

Edit question details when you need to correct instructions, metadata, constraints, or other reusable content in the question library. Review dependencies before changing a question used by active assessments.

# Prerequisites

- Permission to edit questions in **HackerRank for Work**.
- The question you want to update.
- The intended replacement content.

# Edit a question

To edit question details:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Library** and locate the question.
3. Open the question details and select **Edit**.
4. Review the existing problem statement, metadata, constraints, and other configurable fields.
5. Update only the information that needs to change.
6. Review examples and instructions for consistency with the new content.
7. Select **Save**.
8. Reopen or preview the question to verify the final content.

**Note:** If the question is used in multiple assessments, consider the effect of the change on future candidates before editing shared content.

For historical comparisons, see [📄 View Question Version History](/articles/9819273618).
