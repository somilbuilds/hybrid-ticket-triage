# Duplicate Question Warning

_Last updated: August 30, 2026, 2:25 PM (Last updated 18 days ago)_

HackerRank for Work may warn you when a question being created, imported, or added to a library appears to duplicate an existing question. Review the matching questions before creating another copy.

# Prerequisites

- You must have access to the question library.
- You must have permission to create or manage questions.
- Determine whether the question is intended to be new or a copy of an existing question.

# Reviewing a duplicate warning

To review a duplicate question warning:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Library** and select **Questions**.
3. Search for the question by title, topic, or other available attributes.
4. Review any questions identified as possible matches.
5. Open the matching question and compare its problem statement, constraints, test cases, and evaluation settings.
6. If an existing question meets your requirements, use the existing question instead of creating another copy where appropriate.
7. If the question is intentionally different, continue creating or importing it and review the resulting question carefully.
8. Save the question after confirming the configuration.

**Note:** Similar titles or problem statements do not always mean two questions are functionally identical. Review the complete question and evaluation behavior before deciding whether a duplicate should be retained.

If a question was imported and appears duplicated, verify whether the original question already exists in the destination library. See [📄 Question Import and Export](/articles/7398524160).
