# Set Question Difficulty

_Last updated: July 30, 2026, 11:50 AM (Last updated 1 month ago)_

Question difficulty helps teams select content appropriate for an assessment. Set difficulty consistently using the skills, expected solution complexity, and intended candidate level.

# Prerequisites

- Permission to manage questions in **HackerRank for Work**.
- A question in the library.
- An agreed difficulty convention for your organization.

# Update difficulty

To set question difficulty:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Library** and locate the question.
3. Open the question details or editing view.
4. Locate the **Difficulty** field.
5. Select the difficulty level that matches the question's intended complexity.
6. Review the question against other questions in the same category for consistency.
7. Select **Save**.
8. Search or filter the library using the updated difficulty to verify that the question is categorized correctly.

**Note:** Difficulty should describe the expected challenge for the intended candidate population, not simply the amount of code in a solution.

For broader organization, see [📄 Manage Question Tags and Categories](/articles/9921384729).
