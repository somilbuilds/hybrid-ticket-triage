# Learning Path Completion Rules

_Last updated: August 27, 2026, 10:10 AM (Last updated 3 weeks ago)_

Learning path completion depends on the activities and completion criteria configured for the path. Use the learning path details to determine why a learner may still appear incomplete.

# Prerequisites

- Manager or administrator access to **HackerRank for Work** SkillUp content.
- An existing learning path.
- A learner assigned to the path.

# Review completion requirements

To review completion rules:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **SkillUp** and select the relevant **Learning Path**.
3. Review the activities included in the path.
4. Check whether activities require completion, a passing score, or another configured condition.
5. Compare the learner's activity status with the path requirements.
6. Confirm that all required activities are completed according to the configured criteria.
7. Save any required path changes and allow learner progress to update.
8. Recheck the learner's completion status from the path or manager reporting view.

**Note:** Completing an individual activity does not always mean the entire learning path is complete. A learner may still have another required activity or score threshold outstanding.

For assigning paths, see [📄 Assign Learning Path](/articles/7136502849).
