# Assign Learning Path

_Last updated: August 29, 2026, 12:10 PM (Last updated 19 days ago)_

You can assign a learning path to users in HackerRank for Work to provide a structured set of learning content and track progress.

# Prerequisites

- You must have permission to manage learning paths.
- The learning path must already be available in your SkillUp library.
- The users you want to assign must belong to your HackerRank for Work organization.

# Assigning a learning path

To assign a learning path:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **SkillUp** and open **Learning Paths**.
3. Select the learning path you want to assign.
4. Click **Assign**.
5. Select the users, groups, or teams who should receive the learning path.
6. Configure the **Due Date** if your organization requires learners to complete the path by a specific date.
7. Review the selected learners and assignment settings.
8. Click **Assign Learning Path** to confirm the assignment.
9. Open the assignment details to verify that the selected users have been added.

**Note:** Assigning a learning path does not automatically enroll users who are not members of your HackerRank for Work organization. Add the users to the appropriate organization or team before assigning the learning path.

After assignment, learners can access the learning path from their SkillUp dashboard. You can review completion status and progress from the learning path's assignment details. For managing learning content, see [📄 Manage Learning Paths](/articles/6284173059).
