# Set a Learning Path Deadline

_Last updated: July 27, 2026, 10:45 AM (Last updated 1 month ago)_

Set a deadline when learners need to complete a learning path within a defined period. Review existing assignments before changing a deadline for active learners.

# Prerequisites

- Manager or administrator access to **HackerRank for Work** SkillUp.
- An existing learning path.
- The intended completion date and time zone.

# Configure the deadline

To set a learning path deadline:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **SkillUp** and select the relevant **Learning Path**.
3. Open the path settings or assignment configuration.
4. Locate the **Deadline** or completion-date setting.
5. Enter the required date and confirm the applicable time zone.
6. Review how the deadline affects existing learner assignments.
7. Select **Save**.
8. Verify the deadline from a learner assignment or manager reporting view.

**Note:** Changing a deadline for an active path may affect learners who already received the assignment. Communicate significant deadline changes to learners and managers when appropriate.

For completion behavior, see [📄 Learning Path Completion Rules](/articles/9254617052).
