# Remove a Learner From a Learning Path

_Last updated: July 9, 2026, 2:30 PM (Last updated 2 months ago)_

Remove a learner from a learning path when the assignment is no longer applicable. Review the learner's existing progress before changing an active assignment.

# Prerequisites

- Manager or administrator access to **HackerRank for Work** SkillUp.
- The learner's account.
- The relevant learning path.

# Remove the assignment

To remove a learner:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **SkillUp** and select the relevant **Learning Path**.
3. Open the learner or assignment list.
4. Search for the learner you want to remove.
5. Review the learner's current completion status and progress.
6. Select the available **Remove**, **Unassign**, or equivalent action.
7. Confirm the change.
8. Verify that the learner no longer appears as an active assignee for the learning path.

**Note:** Removing an assignment can change the learner's active workload and reporting totals. Preserve any progress or completion information required by your organization's learning records.

For deactivating a learner account, see [📄 Deactivate or Reactivate Learner](/articles/8641739250).
