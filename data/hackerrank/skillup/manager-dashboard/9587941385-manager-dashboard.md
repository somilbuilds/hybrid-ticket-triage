# Manager Dashboard

_Last updated: August 24, 2026, 9:30 AM (Last updated 4 weeks ago)_

The manager dashboard provides a consolidated view of learner activity and progress in SkillUp. Use filters and learner details to identify completed work, outstanding assignments, and progress trends.

# Prerequisites

- Manager or reporting permissions in **HackerRank for Work**.
- Learners assigned to the manager's reporting scope.
- Relevant SkillUp assignments or learning paths.

# Review learner progress

To use the manager dashboard:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **SkillUp** and select **Manager Dashboard**.
3. Review the available learner and team summary metrics.
4. Filter the dashboard by team, learner, learning path, or status when available.
5. Select a learner to inspect individual progress and outstanding activities.
6. Compare completed and incomplete assignments against the expected learning schedule.
7. Export dashboard data when an export option is available and your permissions allow it.
8. Refresh the dashboard after recent learner activity if the displayed results appear outdated.

**Note:** Dashboard metrics may not update immediately after an activity is completed. If a learner's progress is missing, first confirm that the activity itself shows the expected completion status.
