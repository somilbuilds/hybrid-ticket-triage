# Whiteboard and Code Editor Issue

_Last updated: August 29, 2026, 3:50 PM (Last updated 19 days ago)_

This article provides troubleshooting steps when the whiteboard or code editor does not load, respond, or behave as expected during a HackerRank for Work interview.

# Prerequisites

- The interviewer and candidate must be in the active interview session.
- Use a supported browser.
- Confirm whether the issue affects the whiteboard, code editor, or both.

# Troubleshooting the interview workspace

To troubleshoot the whiteboard or code editor:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Interviews** and select the active interview.
3. Confirm that both participants are using the current interview session.
4. Refresh the interview page if the workspace has not loaded.
5. Verify that the browser is up to date and that required site permissions are enabled.
6. Disable browser extensions that may interfere with interactive page content.
7. If the code editor is affected, verify that the selected programming language is supported for the question.
8. Reopen the affected editor or whiteboard from the interview interface.
9. If the problem continues, try the interview in another supported browser.

**Note:** Refreshing an active interview can affect unsaved changes. Preserve important code or notes before refreshing whenever possible.

If the workspace remains unavailable, record the browser, operating system, interview ID, and affected feature before contacting support. See [📄 Interviewer Audio and Video Issue](/articles/3185276490).
