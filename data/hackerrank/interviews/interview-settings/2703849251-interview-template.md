# Create an Interview Template

_Last updated: August 12, 2026, 2:05 PM (Last updated 1 month ago)_

Interview templates standardize recurring interview setups by reusing common questions, settings, and interviewer workflows. Create templates for interview types that your team runs repeatedly.

# Prerequisites

- Permission to manage interviews in **HackerRank for Work**.
- A defined interview structure.
- Questions or resources that should be included in the template.

# Create a template

To create an interview template:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Interviews** and locate the template or interview configuration area.
3. Select **Create Template** or the available template-creation option.
4. Enter a descriptive template name.
5. Add the questions, coding environment, and other standard resources.
6. Configure interviewer and candidate settings that should apply to new interviews.
7. Review the template configuration.
8. Select **Save**.
9. Create a test interview from the template and verify the resulting setup before using it in production.

**Note:** Keep templates focused on a specific interview type. If a template contains assumptions that apply only to one team or role, document those requirements so it is not reused incorrectly.

For interviewer permissions, see [📄 Interview Permissions and Roles](/articles/9032495830).
