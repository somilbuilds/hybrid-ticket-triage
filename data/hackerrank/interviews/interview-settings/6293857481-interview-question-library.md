# Add Questions From the Interview Library

_Last updated: July 13, 2026, 3:15 PM (Last updated 2 months ago)_

Use questions from the reusable library when creating interviews so interviewers can work from consistent technical content and evaluation criteria.

# Prerequisites

- Interview-management access in **HackerRank for Work**.
- Questions available in the interview library.
- An interview or interview template to configure.

# Add a library question

To add a question:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Interviews** and select an existing interview or template.
3. Open the **Questions** or content configuration.
4. Select the option to add a question from the library.
5. Search by question name, skill, tag, or category when available.
6. Select the question you want to use.
7. Review the question and any interviewer-facing guidance.
8. Save the interview configuration and preview the interview before the session.

**Note:** Review shared questions before using them in sensitive interview workflows. A question may have been edited since your team last used it.

For question organization, see [📄 Manage Question Tags and Categories](/articles/9921384729).
