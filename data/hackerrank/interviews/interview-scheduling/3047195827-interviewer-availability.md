# Set Interviewer Availability

_Last updated: July 28, 2026, 3:00 PM (Last updated 1 month ago)_

Set interviewer availability to help scheduling workflows offer appropriate interview times. Keep availability aligned with the interviewer's working hours and connected calendar.

# Prerequisites

- Interview scheduling access in **HackerRank for Work**.
- The interviewer's working hours.
- Calendar access when a calendar integration is used.

# Configure availability

To set interviewer availability:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Interviews** or the interview scheduling settings.
3. Select the interviewer whose availability you want to update.
4. Open the **Availability** settings.
5. Set the applicable working days and time windows.
6. Confirm the time zone used for the availability schedule.
7. Save the changes.
8. Review a scheduling flow or available interview slots to confirm the expected times are offered.

**Note:** Availability settings and calendar events can both affect scheduling. If a time is unexpectedly unavailable, check the connected calendar before widening the availability window.

For permission issues, see [📄 Interview Permissions and Roles](/articles/9032495830).
