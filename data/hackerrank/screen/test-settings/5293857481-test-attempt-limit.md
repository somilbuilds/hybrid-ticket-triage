# Configure Test Attempt Limits

_Last updated: July 23, 2026, 2:15 PM (Last updated 1 month ago)_

Attempt limits control how many times a candidate can access or complete an assessment. Configure the limit before invitations are sent and review exceptions separately.

# Prerequisites

- Permission to edit tests in **HackerRank for Work**.
- An existing assessment.
- A defined number of permitted attempts.

# Set the attempt limit

To configure attempts:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** and select the assessment.
3. Open **Test Settings**.
4. Locate the **Attempt Limit** or candidate access setting.
5. Enter the permitted number of attempts.
6. Review whether existing candidate invitations are affected by the change.
7. Select **Save**.
8. Verify the setting from a test preview or controlled candidate workflow.

**Note:** Do not reset a candidate's attempt simply to bypass an attempt limit unless your assessment policy permits another attempt. Record approved exceptions separately when required.

For resetting attempts, see [📄 Reset a Candidate Test Attempt](/articles/2036179584).
