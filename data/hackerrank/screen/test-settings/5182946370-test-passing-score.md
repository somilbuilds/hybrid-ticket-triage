# Set the Test Passing Score

_Last updated: July 24, 2026, 10:05 AM (Last updated 1 month ago)_

Set a passing score when your assessment workflow requires candidates to meet a defined threshold. Review scoring behavior before publishing the test.

# Prerequisites

- Permission to edit tests in **HackerRank for Work**.
- A defined passing threshold for the assessment.
- An existing test with scoring configured.

# Configure the passing score

To set the passing score:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** and select the relevant assessment.
3. Open **Test Settings** or the scoring configuration.
4. Locate the **Passing Score** setting.
5. Enter the required threshold according to your hiring workflow.
6. Review how individual questions contribute to the total score.
7. Select **Save**.
8. Preview the test or review a sample result to confirm the expected pass/fail behavior.

**Note:** A passing score is meaningful only when the assessment's scoring configuration is understood. Check weighted questions and sections before changing the threshold.

For result troubleshooting, see [📄 Candidate Score Not Calculated](/articles/1703846251).
