# Configure Test Question Randomization

_Last updated: August 6, 2026, 2:05 PM (Last updated 1 month ago)_

Question randomization can provide different question sequences or selections to candidates while preserving the intended assessment structure. Review the configuration before publishing the test.

# Prerequisites

- Permission to edit tests in **HackerRank for Work**.
- A test containing the questions to randomize.
- A defined question-selection strategy.

# Configure randomization

To configure question randomization:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** and select the assessment.
3. Open the test's **Settings** or question configuration.
4. Locate the available question randomization or question-selection option.
5. Choose whether questions should be presented in a randomized order or selected from a configured pool.
6. Review the number and type of questions included in each section.
7. Save the configuration.
8. Preview or test the assessment to verify that the resulting question set matches your intended design.

**Note:** Randomization does not replace careful question-pool design. Make sure questions in the same pool have comparable difficulty and test the same intended skills.

For question organization, see [📄 Manage Question Tags and Categories](/articles/9921384729).
