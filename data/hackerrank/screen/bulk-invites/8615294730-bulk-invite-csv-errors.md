# Bulk Invite CSV Errors

_Last updated: August 28, 2026, 4:10 PM (Last updated 20 days ago)_

This article explains how to troubleshoot errors when uploading a CSV file for bulk candidate invitations in HackerRank for Work. Check the file structure, required fields, and candidate email addresses before uploading again.

# Prerequisites

- You must have permission to invite candidates to the test.
- Prepare the candidate list as a CSV file.
- Confirm that each candidate has a valid email address.

# Fixing CSV upload errors

To troubleshoot a bulk invite CSV:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the test where candidates should be invited.
3. Select the **Candidates** or bulk invitation option.
4. Download the available CSV template if one is provided.
5. Make sure the column headers match the template exactly.
6. Check that required fields are populated and that email addresses are valid.
7. Remove blank rows, duplicate entries, and unsupported characters from the file.
8. Save the file as a CSV and upload it again.
9. Review the upload results for rows that were rejected.

**Note:** Spreadsheet applications can change CSV formatting automatically. If an upload reports specific rows as invalid, correct only those rows and upload the file again rather than changing the entire candidate list.

If the upload succeeds but some candidates do not receive invitations, verify their email addresses and invitation status. For individual invitations, see [📄 Resend Invite Email](/articles/4398627153).
