# Bulk Invite Candidates

_Last updated: September 6, 2026, 9:05 AM (Last updated 2 weeks ago)_

Use bulk invitations when the same assessment needs to be assigned to multiple candidates. Preparing the candidate list before upload helps prevent invalid addresses and duplicate invitations.

# Prerequisites

- A published test in **HackerRank for Work**.
- Candidate email addresses in a supported file format.
- Permission to invite candidates.

# Upload a candidate list

To invite multiple candidates:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** and select the assessment.
3. Select **Invite Candidates**.
4. Choose the bulk-upload option.
5. Prepare the candidate file with one candidate per row and a valid email address.
6. Upload the file and review the validation results.
7. Correct any rejected rows and upload the corrected file if required.
8. Select **Send Invites** after confirming the final candidate list.

**Note:** Keep the uploaded file free of blank email rows, malformed addresses, and accidental duplicate entries. If the upload reports errors, correct the source file instead of repeatedly submitting the same invalid file.

If your upload fails, see [📄 Bulk Invite CSV Errors](/articles/8615294730).
