# Candidate Test Link Not Working

_Last updated: August 7, 2026, 10:15 AM (Last updated 1 month ago)_

If a candidate reports that an assessment link does not open, first verify that the invitation is valid and that the candidate is using the intended link in a supported browser.

# Prerequisites

- Access to the relevant **HackerRank for Work** test.
- Permission to manage candidates.
- The candidate's invitation email or test URL.

# Troubleshoot the test link

To investigate a test link:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Tests** and select the relevant assessment.
3. Select **Candidates** and locate the candidate.
4. Confirm that the candidate was invited to the test and that the invitation has not expired.
5. Compare the link used by the candidate with the current invitation link.
6. Ask the candidate to open the link in a supported, updated browser.
7. Ask the candidate to retry without an outdated browser extension or cached page.
8. If the link still fails, record the exact error message and time of the attempt for investigation.

**Note:** Do not assume that generating a new test link is required. An expired invitation, incorrect candidate email, or browser restriction can produce similar symptoms.

For authorization errors, see [📄 Test Link Says Unauthorized](/articles/7418263095).
