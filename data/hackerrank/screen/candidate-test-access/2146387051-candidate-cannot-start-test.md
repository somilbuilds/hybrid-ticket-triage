# Candidate Cannot Start Test

_Last updated: September 3, 2026, 10:15 AM (Last updated 14 days ago)_

This article explains how to troubleshoot situations where a candidate cannot start a HackerRank for Work test after receiving an invitation. Check the candidate's invitation, test availability, and access details before sending a new invitation.

# Prerequisites

- You must have access to the relevant test in HackerRank for Work.
- The candidate must have an existing invitation or candidate record.
- Confirm that the test is currently available.

# Troubleshooting candidate access

To troubleshoot a candidate who cannot start a test:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the relevant test.
3. Select **Candidates** and search for the candidate by name or email address.
4. Verify that the candidate has an active invitation.
5. Check the test's **Start Date**, **End Date**, and **Test Duration**.
6. Confirm that the candidate is using the email address associated with the invitation.
7. If the invitation is inactive or expired, select the candidate and click **Resend Invite**.
8. Ask the candidate to open the latest invitation in a supported browser.
9. If the candidate still cannot start the test, ask them to use an incognito window and open the link directly from the latest email.

**Note:** A candidate cannot start a test when the invitation has expired or been revoked, the testing window has closed, or the candidate is accessing the invitation with a different email address.

If the issue persists, review [📄 Test Link Says Unauthorized](/articles/6382051749) for additional access checks.
