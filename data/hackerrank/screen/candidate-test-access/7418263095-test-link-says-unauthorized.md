# Test Link Says Unauthorized

_Last updated: September 5, 2026, 10:20 AM (Last updated 12 days ago)_

This article explains how to troubleshoot an Unauthorized message when a candidate opens a HackerRank for Work test link.

# Prerequisites

- Confirm that the candidate has received an invitation for the test.
- Verify the email address used for the invitation.
- Confirm that the test invitation is still active.

# Troubleshooting an unauthorized link

To resolve an Unauthorized message:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the relevant test.
3. Select **Candidates** and locate the candidate.
4. Verify that the candidate's email address matches the address used to access the invitation.
5. Check whether the candidate's invitation has expired, been revoked, or already been replaced.
6. If necessary, select the candidate and click **Resend Invite**.
7. Ask the candidate to open the newest invitation link in a private or incognito browser window.
8. Ask the candidate to sign in with the account or email address associated with the invitation.
9. If the error continues, ask the candidate to avoid using an old bookmarked link and open the URL directly from the latest invitation.

**Note:** An invitation link is associated with the candidate and test invitation. Opening the link while signed in with a different account or using an outdated invitation can result in an Unauthorized message.

If the candidate continues to see the error after a new invitation is sent, verify that the test is active and that the candidate is listed as an eligible participant. For expired invitations, see [📄 Candidate Test Expired](/articles/5173048621).
