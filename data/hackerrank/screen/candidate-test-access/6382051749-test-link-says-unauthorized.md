# Test Link Says Unauthorized

_Last updated: September 4, 2026, 9:45 AM (Last updated 13 days ago)_

This article explains how to troubleshoot an Unauthorized message displayed when a candidate opens a HackerRank for Work test invitation.

# Prerequisites

- The candidate must have received an invitation for the test.
- You must have access to the candidate's test record.
- Confirm that the test and invitation are still active.

# Troubleshooting the access error

To troubleshoot an Unauthorized message:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the relevant test.
3. Select **Candidates** and locate the candidate.
4. Verify that the email address on the candidate record matches the address used to access the invitation.
5. Check the candidate's invitation status and test availability dates.
6. If the invitation is expired or inactive, select **Resend Invite**.
7. Ask the candidate to open the newest invitation in an incognito or private browser window.
8. Ask the candidate to sign in using the email address associated with the invitation.
9. Ask the candidate to avoid using an old bookmarked link.

**Note:** The Unauthorized message can appear when a candidate uses an outdated invitation or accesses the link while signed in with a different account.

If a newly issued invitation also produces the error, verify that the candidate is eligible for the test and that the test has not been disabled. See [📄 Candidate Cannot Start Test](/articles/2146387051).
