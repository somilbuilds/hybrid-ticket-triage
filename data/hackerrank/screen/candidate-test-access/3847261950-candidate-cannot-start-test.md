# Candidate Cannot Start Test

_Last updated: August 28, 2026, 3:15 PM (Last updated 20 days ago)_

This article explains how to troubleshoot cases where a candidate cannot start an assessment after receiving a HackerRank for Work test invitation.

# Prerequisites

- The candidate must have received a valid test invitation.
- You must have access to the relevant test in your HackerRank for Work account.
- Confirm that the test has not expired or been disabled.

# Troubleshooting candidate test access

To help a candidate who cannot start a test:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the test assigned to the candidate.
3. Select **Candidates** and locate the candidate's email address.
4. Verify that the candidate's status shows an active invitation.
5. Check the **Test Duration**, **Start Date**, and **End Date** configured for the test.
6. Confirm that the candidate is using the email address associated with the invitation.
7. If the invitation is no longer active, select the candidate and click **Resend Invite**.
8. Ask the candidate to open the new invitation from a supported browser and use the **Start Test** option.
9. If the candidate still cannot start the test, ask them to clear their browser cache or try an incognito window.

**Note:** A candidate cannot start a test if the test has expired, the invitation has been revoked, or the candidate is attempting to use an invitation associated with a different email address.

If the issue persists after sending a new invitation, review [📄 Resending a Test Invitation](/articles/4729183056) and verify that the test configuration allows the candidate to access the assessment.
