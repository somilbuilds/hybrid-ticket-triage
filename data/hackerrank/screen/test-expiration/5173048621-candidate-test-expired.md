# Candidate Test Expired

_Last updated: September 2, 2026, 11:40 AM (Last updated 15 days ago)_

This article explains what happens when a candidate's test invitation expires and how to provide the candidate with a new active invitation.

# Prerequisites

- You must have access to the test in your HackerRank for Work account.
- The candidate must have an existing invitation or candidate record.
- Confirm that the test should still be available to the candidate.

# Checking an expired test

To verify whether a candidate's test has expired:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and select the relevant test.
3. Open the **Candidates** tab.
4. Search for the candidate by name or email address.
5. Review the candidate's invitation status and the configured test availability period.
6. If the test is outside its configured **End Date**, the candidate cannot start the test using the expired invitation.

# Sending a new invitation

To give the candidate access to an expired test:

1. Open the candidate's record from the **Candidates** tab.
2. Select **Resend Invite**.
3. If prompted, update the test availability dates so that the candidate has an active testing window.
4. Confirm the candidate's email address.
5. Click **Send** to issue the new invitation.
6. Ask the candidate to use the latest invitation email rather than an older test link.

**Note:** Resending an invitation does not make an expired testing window active. If the test itself has reached its configured end date, update the test's availability before sending the invitation again.

The candidate's previous invitation may continue to display an expired status. The latest invitation should be used to access the active testing window. For additional access troubleshooting, see [📄 Candidate Cannot Start Test](/articles/3847261950).
