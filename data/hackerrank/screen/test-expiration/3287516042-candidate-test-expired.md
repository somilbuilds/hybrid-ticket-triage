# Candidate Test Expired

_Last updated: September 1, 2026, 2:30 PM (Last updated 16 days ago)_

This article explains how to verify an expired candidate test and restore access when the candidate needs additional time to complete the assessment.

# Prerequisites

- You must have permission to manage the test.
- The candidate must be listed under the test's **Candidates** tab.
- Confirm that the candidate should receive another testing opportunity.

# Checking the test expiration

To check whether a candidate's test has expired:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and select the relevant test.
3. Open the **Candidates** tab.
4. Search for the candidate and open the candidate's details.
5. Review the invitation status and the configured **Start Date** and **End Date**.
6. Confirm whether the candidate's testing window has ended.

# Reissuing access

To provide access again:

1. Update the test availability dates if the current testing window has ended.
2. Return to the candidate's record.
3. Select **Resend Invite**.
4. Verify the candidate's email address.
5. Click **Send**.
6. Ask the candidate to use the newest invitation instead of the previous expired link.

**Note:** Resending an invitation does not extend a test that is no longer available. The test availability window must be active before the candidate can use a new invitation.

If the candidate has already started the test, review the test's attempt and retake settings before sending another invitation. See [📄 Managing Candidate Test Attempts](/articles/5842107631).
