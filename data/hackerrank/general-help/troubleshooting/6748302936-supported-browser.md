# Check Supported Browser Requirements

_Last updated: July 8, 2026, 10:20 AM (Last updated 2 months ago)_

Browser compatibility can affect assessments, interviews, authentication, and other HackerRank for Work workflows. Use an updated supported browser when troubleshooting unexpected behavior.

# Prerequisites

- Access to the affected HackerRank for Work workflow.
- An updated browser.
- The browser version and operating system used by the affected user.

# Check browser compatibility

To troubleshoot a browser issue:

1. Log in to your **HackerRank for Work** account using your credentials when possible.
2. Record the browser name, version, and operating system.
3. Confirm that the browser is supported for the workflow being used.
4. Update the browser if a newer supported version is available.
5. Disable unnecessary extensions that may modify page behavior.
6. Retry the workflow in a private or incognito window when appropriate.
7. Test the same workflow in another supported browser.
8. Record any differences and the exact error message if the issue continues.

**Note:** Browser behavior can differ between candidate assessments and administrator workflows. Test the same workflow type when comparing results.

For cached-page issues, see [📄 Clear Browser Cache and Cookies](/articles/4370418250).
