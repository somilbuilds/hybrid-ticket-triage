# Audit Log Export

_Last updated: September 1, 2026, 4:45 PM (Last updated 16 days ago)_

You can export available audit log records from HackerRank for Work to review organization activity outside the application. Use filters to limit the export to the events and time period you need.

# Prerequisites

- You must have permission to view audit logs.
- Confirm the date range and event types you want to export.
- Make sure your browser allows file downloads.

# Exporting audit logs

To export audit log activity:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Settings** and open **Audit Logs**.
3. Select the required **Date Range**.
4. Apply **Event Type**, **User**, or other available filters.
5. Review the filtered audit events.
6. Click **Export** or **Download**.
7. Select the available file format if prompted.
8. Save the exported file to your device.
9. Open the file and verify that it contains the expected events and date range.

**Note:** The export contains only events available to your account and within the selected filters. Recent activity may take some time to appear in the audit log.

If an export is empty, first remove restrictive filters and use a broader date range. If the export option is unavailable, verify that your role includes audit log access. See [📄 Managing Organization Audit Logs](/articles/6174293058).
