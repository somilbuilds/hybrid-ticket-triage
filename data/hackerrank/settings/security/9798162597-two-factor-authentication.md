# Two-Factor Authentication

_Last updated: September 2, 2026, 1:15 PM (Last updated 2 weeks ago)_

Two-factor authentication adds an additional verification step when users sign in to HackerRank for Work. Administrators can review the organization's authentication requirements and users can complete the enrollment flow when prompted.

# Prerequisites

- Access to your **HackerRank for Work** account.
- An approved authentication method supported by your organization.
- Administrator access if you are changing organization-wide requirements.

# Configure authentication

To review two-factor authentication settings:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Settings** and select **Security** or the organization's authentication settings.
3. Review the current two-factor authentication requirement.
4. If you are an administrator, enable or update the requirement according to your organization's policy.
5. Save the configuration when prompted.
6. Sign out and sign back in to confirm that the expected verification step appears.
7. If a user cannot complete verification, confirm that the user can access the configured authentication method before changing organization settings.

**Note:** Authentication settings can affect many users. Test organization-wide changes with an appropriate administrator account before communicating the new sign-in process to the team.

For account access problems, see [📄 Reset Password](/articles/6381592740).
