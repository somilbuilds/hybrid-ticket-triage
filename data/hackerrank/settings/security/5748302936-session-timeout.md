# Configure Session Timeout

_Last updated: July 18, 2026, 1:45 PM (Last updated 2 months ago)_

Session timeout controls how long an authenticated HackerRank for Work session can remain inactive before the user must sign in again. Review the setting with your organization's security requirements.

# Prerequisites

- Organization administrator access.
- A defined inactivity period.
- Awareness of how the change may affect active users.

# Update session timeout

To configure the timeout:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Settings** and select **Security**.
3. Locate the **Session Timeout** or session security setting.
4. Review the current inactivity period.
5. Select the duration required by your organization's policy.
6. Review the effect on active sessions and users.
7. Select **Save**.
8. Test the behavior with an authorized account after the configuration is applied.

**Note:** A shorter timeout can require users to authenticate more frequently. Communicate organization-wide changes before applying them to avoid unexpected interruptions.

For additional authentication controls, see [📄 Two-Factor Authentication](/articles/9798162597).
