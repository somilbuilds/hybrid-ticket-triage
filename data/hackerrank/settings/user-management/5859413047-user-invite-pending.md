# User Invitation Is Pending

_Last updated: July 17, 2026, 9:15 AM (Last updated 2 months ago)_

A pending user invitation means the invited team member has not completed the available account-activation flow. Verify the address and email delivery before sending another invitation.

# Prerequisites

- User-management access in **HackerRank for Work**.
- The invited user's email address.
- Permission to resend user invitations.

# Manage a pending invitation

To troubleshoot a pending invitation:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Settings** and select **User Management**.
3. Search for the invited user by email address.
4. Confirm that the invitation is still pending and that the address is correct.
5. Ask the user to check spam, junk, and quarantine folders.
6. Confirm that the user's organization permits messages from the configured HackerRank for Work sender.
7. Use the available **Resend Invite** action if the user still needs the invitation.
8. Verify that the user's status changes after they complete the activation process.

**Note:** If the email address is incorrect, correct the invitation recipient before resending. Avoid creating a second account with a different address unless your organization explicitly requires it.

For adding team members, see [📄 Invite and Manage Team Members](/articles/9687951486).
