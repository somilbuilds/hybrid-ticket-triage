# User Locked Out

_Last updated: August 26, 2026, 9:50 AM (Last updated 22 days ago)_

This article explains how to troubleshoot a user account that is locked out of HackerRank for Work and how an administrator can restore access.

# Prerequisites

- You must have administrator access to the HackerRank for Work account.
- Confirm the user's email address.
- Verify whether the user is locked out because of login attempts, account status, or authentication settings.

# Restoring user access

To help a locked-out user:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Settings** and open **Users**.
3. Search for the affected user by name or email address.
4. Open the user's profile and review the account status.
5. If the account is disabled, use the available **Enable User** option.
6. If your organization uses single sign-on, verify that the user is active in the organization's identity provider.
7. Ask the user to sign in again using the correct work email address.
8. If the user has forgotten their password and password authentication is enabled, ask them to use **Forgot Password** on the sign-in page.
9. If access is still blocked, verify that the user's organization membership and assigned permissions are correct.

**Note:** For accounts using single sign-on, password resets in HackerRank for Work do not resolve authentication problems managed by the identity provider. The user's SSO account must be active and authorized to access HackerRank for Work.

If the user can sign in but cannot access specific features, review their assigned role and permissions rather than treating the issue as a locked account. See [📄 Managing Users and Roles](/articles/2746183950).
