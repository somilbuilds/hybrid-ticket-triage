# Change a User Role

_Last updated: August 1, 2026, 10:25 AM (Last updated 1 month ago)_

Update a user's role when their responsibilities change. Review the permissions associated with the new role before saving the change.

# Prerequisites

- Organization administrator or user-management permissions.
- The user's email address.
- The intended role and required access.

# Update the role

To change a user role:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Settings** and select **User Management**.
3. Search for the user by email address.
4. Open the user's profile or access settings.
5. Review the current role and permissions.
6. Select the new **Role** that matches the user's responsibilities.
7. Review the resulting access and confirm that it is appropriate.
8. Select **Save**.
9. Ask the user to sign in again if their access does not update immediately.

**Note:** A role change can grant or remove access to multiple resources. Check the user's new permissions before applying the change, especially for administrator-level roles.

For role-related troubleshooting, see [📄 Role Permission Missing](/articles/9625483170).
