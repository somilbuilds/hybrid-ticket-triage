# Remove User Access

_Last updated: August 2, 2026, 1:10 PM (Last updated 1 month ago)_

Remove access when a team member leaves the organization or no longer needs access to HackerRank for Work. Review ownership and active assignments before deactivating the account.

# Prerequisites

- Organization administrator access.
- The user's email address.
- Confirmation that the user no longer requires access.

# Remove access

To remove a user's access:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Open **Settings** and select **User Management**.
3. Search for the user by email address.
4. Review the user's role, owned resources, and relevant assignments.
5. Transfer ownership of resources that must remain available to another administrator.
6. Select the available **Deactivate**, **Remove Access**, or equivalent action.
7. Confirm the change.
8. Verify that the user no longer has the expected organization access.

**Note:** Deactivating a user can affect resources they own or workflows they manage. Transfer required ownership before removing access.

For ownership changes, see [📄 Transfer Resource Ownership](/articles/1738264950).
