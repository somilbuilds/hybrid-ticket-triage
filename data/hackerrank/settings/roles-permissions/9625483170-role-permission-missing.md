# Role Permission Missing

_Last updated: August 31, 2026, 9:35 AM (Last updated 17 days ago)_

This article explains how to troubleshoot a user who cannot access a HackerRank for Work feature because the required role permission is missing.

# Prerequisites

- You must have administrator permission to manage roles.
- Confirm the user and feature they need to access.
- Identify the role currently assigned to the user.

# Checking role permissions

To resolve a missing permission:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Settings** and select **Roles** or **Roles and Permissions**.
3. Locate the role assigned to the affected user.
4. Open the role and review its available permissions.
5. Identify the permission required for the feature or action.
6. Enable the required permission if it is appropriate for the user's role.
7. Save the role changes.
8. Return to **Users** and verify that the affected user has the correct role.
9. Ask the user to refresh HackerRank for Work or sign in again before testing access.

**Note:** Permission changes can affect every user assigned to the role. If only one user requires additional access, consider assigning an appropriate role rather than changing a broadly used role without reviewing its impact.

If the user still cannot access the feature, verify team-level restrictions and organization membership. See [📄 Managing Users and Roles](/articles/3617952048).
