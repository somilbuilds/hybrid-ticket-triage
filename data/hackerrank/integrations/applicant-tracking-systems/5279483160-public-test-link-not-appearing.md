# Public Test Link Not Appearing in ATS

_Last updated: August 30, 2026, 4:05 PM (Last updated 18 days ago)_

This article explains how to troubleshoot a public HackerRank for Work test link that is not appearing in an applicant tracking system. Check the test configuration and ATS integration before recreating the test.

# Prerequisites

- The ATS integration must be connected.
- The test must have a public link enabled, where supported.
- You must have permission to manage tests and integration settings.

# Troubleshooting the test link

To troubleshoot a missing public test link:

1. Log in to your **HackerRank for Work** account using your credentials.
2. Navigate to **Tests** and open the relevant test.
3. Review the test's **Settings** and confirm that public access or the required link option is enabled.
4. Copy or review the generated test link if one is available.
5. Navigate to **Settings** and select **Integrations**.
6. Open the ATS integration and verify that the connection is active.
7. Confirm that the test is associated with the expected job or workflow.
8. Return to the ATS and refresh the candidate or job record.
9. Check whether the HackerRank action or test link is now displayed.

**Note:** A test link may not appear when the test is not configured for the required access type or when the ATS integration cannot access the associated job. Availability can also depend on the ATS workflow configuration.

If the link remains missing, record the test name, ATS job, integration status, and any displayed error. See [📄 Configure a Test for ATS Integration](/articles/6385172940).
